# TJ Academy — Mentoria MVP

Protótipo inicial para validar uma mentoria de concursos operada pelo mentor.

## Fluxo atual

- Visão do mentor com lista de alunos e execução diária.
- Cadastro manual de tarefas individuais pelo ADM.
- Tempo, número de questões, prioridade e orientação de cada tarefa.
- Visão do aluno orientada para execução do plano do dia.
- Marcação de tarefas concluídas e progresso diário.
- Persistência local no navegador para teste do fluxo.

## Princípio do produto

A inteligência sugere; o mentor decide. O plano do aluno não deve ser gerado ou alterado automaticamente sem supervisão.

## Próxima etapa após validação

1. Supabase Auth + banco de dados.
2. Cadastro real de alunos e concursos.
3. Plano semanal e recorrências.
4. Check-in semanal.
5. Registro de horas, questões e acertos.
6. Sugestões inteligentes baseadas em desempenho, edital e disponibilidade.
7. Relatórios para o mentor aprovar e enviar.
